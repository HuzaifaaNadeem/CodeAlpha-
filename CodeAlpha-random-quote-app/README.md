# QuoteSpark — Signature Mobile Edition

A clean, offline-first Flutter quote application built with Riverpod and local persistence.

## Signature experience

- Mobile-first single-focus quote experience
- Top horizontal mood rail with animated selection
- Mood-aware quote colors and atmosphere
- Fixed bottom action dock for copy, shuffle, and save
- Smooth quote transitions and haptic feedback
- Persistent private favorites stored on-device
- Searchable saved quote collection
- Responsive layouts for mobile, web, and desktop
- Desktop shortcuts: Space = new quote, S = save, C = copy

## Run

```bash
flutter pub get
flutter analyze
flutter test
flutter run -d chrome
```
